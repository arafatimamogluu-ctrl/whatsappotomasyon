# WhatsApp Bulk Message Sender Automation

Profesyonel WhatsApp toplu mesaj gönderim ve otomasyon sistemi.

## 🚀 Özellikler
- **Güvenli Kimlik Doğrulama**: QR kod ile güvenli WhatsApp bağlantısı (whatsapp-web.js).
- **Toplu Mesaj**: Belirlenen gruplara ve kişilere tek tıkla mesaj gönderimi.
- **Medya Desteği**: Metin, resim ve video gönderimi.
- **Zamanlama**: İleri tarihli mesaj planlama.
- **Anti-Ban**: Akıllı gecikme ve limit sistemi ile güvenli gönderim.

## 🛠️ Kurulum

### Gereksinimler
- Node.js (v18+)
- MongoDB

### Backend Kurulumu
```bash
cd backend
npm install
npm run dev
```

### Frontend Kurulumu
```bash
cd frontend
npm install
npm run dev
```

## 📝 Konfigürasyon
`.env` dosyasını kendi ayarlarınızla güncelleyin (MongoDB URI, JWT Secret vb.).

## ⚠️ Uyarı
Bu proje eğitim ve test amaçlıdır. WhatsApp'ın hizmet koşullarına uyunuz. Spam gönderimi yasaktır.
